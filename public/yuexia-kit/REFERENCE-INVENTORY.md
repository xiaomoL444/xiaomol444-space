# 月下参考图：86 项可复用视觉元素观察清单

这是一份对 5 张用户参考图的完整视觉拆解，便于以后筛选、设计和制作个人主页装饰。**清单中的 86 项是观察与复用建议，不代表每一项都已经制作成独立素材。** 清单不用于确认截图中的原字体；字体建议是经过官方仓库核验的风格替代方案。

图号对应：①活动长图；②「月下相续」横版主视觉；③心愿清单；④角色介绍窄图；⑤服装与武器细节长图。

整体可组合为三种视觉语言：黑红哥特主视觉、旧金档案卡片、奶油色手写信纸。

## 制作与组合建议

优先制作单色 SVG 图案、可缩放 SVG 边框与分隔线、CSS 字体和色彩效果。纸纹、红雾、光斑可以制作成单独背景纹理。手写小图保留轻微不对称；金属边框使用严格对称结构。

最容易忽略、也适合反复使用的元素包括相框内侧斜切角、标题牌右下红色折角、页脚断开的菱格、菱格交点四芒星、右侧点状缝线、盾形卡片下缘。

主页优先组合旧金分隔线、倒角作品框、暗红标签、菱形项目符号、手写心愿纸、红宝石小徽记。蝙蝠、玫瑰、红雾、花瓣集中在首屏与页脚，避免所有装饰同时铺满内容区。
